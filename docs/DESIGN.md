# DESIGN — 무엇을 만드는가

이 문서는 요약 자리만 둔다. 실제 설계는 프로젝트 루트의 설계 문서들에 있다.
바퀴는 아래 문서를 필요한 절만 `grep -n`으로 찾아 그 줄 범위만 읽는다(통째로 읽지 않는다).

## 게임 개요

- 제목: 심연의 숨결 (Zero Study RPG)
- 엔진: Godot 4.7 (GDScript)
- 장르: 320×240 피처폰 감성 2D 액션 RPG
- 실행: `project.godot` / macOS 앱 `<저장소>.app`

## 밸런스 숫자 위치

기존 상수 파일은 `scripts/game_state.gd`(스킬·아이템·강화·직업 상수 다수 포함)이다.
새 밸런스 상수를 추가할 자리가 필요하면 이 파일에 잇는다. 별도 `K.gd`는 아직 없다 —
game_state.gd가 이미 이 역할을 하고 있으므로 새 파일을 만들기 전에 먼저 이곳에 넣을 수
있는지 확인한다.

| 레벨 보상 상자 골드 | 40×레벨 | 보스 격파 보상(장별 스케일 예정, INBOX 2026-10-19 23:42)과 비슷한 자릿수로 - Lv5=200·Lv50=2000 |
